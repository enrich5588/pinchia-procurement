# 財產圖片

管理部可在財產清冊的新增、編輯表單一次選取多張圖片，儲存後顯示於清冊。
點選縮圖可開啟原圖；編輯時勾選「移除圖片」，儲存後才會移除。
支援 JPG、PNG、WebP、GIF，每張最多 5 MB，每次最多 10 張，可再編輯追加。
管理部核准資產登記時也能在建檔表單附加圖片。
申請人可在資產登記新增、修改表單上傳或移除多張圖片；單筆與批量核准均會將圖片帶入清冊。
申請圖片只供申請人與管理部查看，核准後清冊圖片另依部門權限提供。
清冊移除由申請帶入的圖片時，仍保留申請原始圖片供查閱。

## 已核准財產的異動

原申請人或目前保管人員可從已核准案件或財產明細選擇「再次修改／申請修改」。系統會建立新的財產異動案件，並保留原財產清冊資料，直到管理部逐筆核准。管理部人員則可直接編輯清冊，不需再次送審。
核准後，異動內容會更新至原財產編號，不會建立第二筆財產；退回或取消均不影響清冊。每筆財產同時間只允許一件申請中或退回的異動案件。
異動時可新增圖片，也可指定核准後要從清冊移除的現有圖片；歷史申請中的圖片仍會保留供查閱。

## 安裝與儲存

```powershell
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe manage.py migrate
```

圖片預設儲存在 `private-media/assets/`，不納入 Git；備份及搬移時須連同資料庫一起保留。
可透過 Django 設定 `ASSET_IMAGE_ROOT` 指定持久化目錄。
該目錄不可由 Web 伺服器直接公開；圖片透過 `/assets/images/<id>/` 檢查登入與部門權限後提供。
一般同仁只能查看所屬部門的圖片，管理部與系統管理員可查看全部圖片。

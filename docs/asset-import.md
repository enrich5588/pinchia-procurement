# 財產清冊批量匯入與覆蓋

財產清冊的「批量上傳」頁上方大區塊就是唯一選檔區，可點選、鍵盤 Enter／空白鍵或拖曳單一 .xlsx；顯示選取檔名，按「讀取並預覽」才送出。上限 150 MB、500 筆。

預設僅新增，已有財產編號會拒絕。需要更新時，先勾選「依財產編號更新既有資料（覆蓋）」；比對忽略編號前後空白及英文大小寫，既有編號更新，未有編號新增。單一檔案內的編號仍不可重複；若既有資料存在大小寫／空白不同而歧義的重複編號，需先整理後再上傳。

上傳只建立預覽，預覽逐列標示新增／覆蓋更新；最終確認才一次寫入。覆蓋模式不可在預覽改變財產編號，需重新上傳以重新比對；其餘可編輯欄位依預覽內容完整寫入，包含選填空值。原主鍵、建立者、建立時間及歷史案件關聯保留，更新者與更新時間會變更。既有圖片不刪除，Excel 新圖片另行新增。任何列驗證失敗整批回滾，操作 LOG 同步回滾；成功後記錄每筆新增／修改及前後值，回報新增、更新與新增圖片數。

上傳時會保存比對對象與版本摘要；若在確認前財產被其他人修改、刪除或被另一筆同編號資料取代，會擋下本次匯入，需重新上傳預覽，不會默默覆蓋較新的資料。上傳及確認均須具備財產管理權，預覽僅限原上傳者確認。匯入模式儲存在批次資料庫，不能靠在確認 POST 增加覆蓋參數而改變模式。

正式環境（DEBUG=False）不呈現測試相容模式／替代部門欄位；後端也拒絕這些參數、替代部門解析及測試模式建立的預覽批次。資產登記上傳同樣適用此限制，但資產登記仍只建立申請，不提供以財產編號直接覆蓋清冊。開發環境才保留測試選項。

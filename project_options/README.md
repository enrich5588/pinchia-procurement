# 集中選項管理

此資料夾集中管理專案內所有「非使用者、非部門」的下拉選單、狀態與固定選項。

## 檔案

- `assets.py`：財產類別、資產登記狀態、資料庫監看更新頻率。
- `procurement.py`：舊用品收單狀態、辦公用品申請狀態、用品名稱選項。

## 手動修改方式

每個選項的格式都是：

```python
程式代碼 = "資料庫儲存值", "畫面顯示文字"
```

例如新增「修正帶」：

```python
CORRECTION_TAPE = "correction_tape", "修正帶"
```

儲存後重新啟動 Django 服務即可生效。

## 注意事項

1. 只修改右側的畫面文字，通常不影響既有資料。
2. 修改或刪除左側程式代碼、資料庫儲存值，可能讓既有資料無法正確顯示，必須同步做資料 migration。
3. 新增的資料庫儲存值不可超過對應模型欄位的 `max_length`。
4. 狀態選項同時被後端流程使用，不應只刪除狀態；需同步調整流程與測試。
5. 使用者與部門是資料庫資料，依需求刻意不放在此資料夾。
